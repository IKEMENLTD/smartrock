■ Claude Code キックオフプロンプト(コピペ用)

このリポジトリの design-docs/ にある設計書(本スプレッドシートをエクスポートした内容)に基づきシステムを実装してください。
手順：
1) まずシート40(README相当)を読み、シート41の実装タスク計画の順に進める。
2) 実装の正本はシート20-27(詳細設計)。API・DB・画面・ジョブの仕様に厳密に従う。特にシート16/25の『SwitchBot createKeyは非同期・idはwebhookで取得・deleteKeyに必須』を必ず実装する。
3) シート31の全テストケース(優先度『高』は必須)を満たすテストを書き、passするまで直す。満たせないTCは原因をIMPLEMENTATION_NOTES.mdに記録し、修正を繰り返さず報告する。
4) 完了の定義(シート40 §6)を全て満たした時点で、実施内容と残課題を要約して報告する。
設計書に未定義の点は、設計意図に沿って前提を置いて進め、判断をIMPLEMENTATION_NOTES.mdに記録してください。スコープ外の機能追加はしないこと。

⚠ スプレッドシートのままでも良いが、Claude Codeに渡す際は各シートをMarkdown/CSVに書き出して design-docs/ 配下へ置くと参照精度が上がる(シート名=ファイル名)。
