# 01_システム概要

要件定義｜システム概要

無人セルフ脱毛サロン 予約・入退室管理システム  /  コード名: sds (Self-Datsumo System)

■ 背景・解決したい課題

・完全無人のセルフ脱毛サロンを開発リソースを活かして低コストで運営したい。スタッフ常駐なしで、予約〜入室〜退室までを自動化する。

・市販の業務用スマートロック(RemoteLOCK等)は月額が高い。SwitchBotロック＋公式APIで『予約ごとの時限パスコード自動発行』を内製し、月額固定費を実質ゼロに抑える。

・予約導線はLINEを主入口とし、空き枠はGoogleカレンダーと連動させて運営者が直感的に管理できるようにする。

■ 目的・ゴール（達成された状態）

・顧客がLINEから3タップ程度で空き枠を選び予約を完了できる。

・予約確定と同時に、その予約時間だけ有効な解錠パスコードがLINEへ自動送信される。

・予約時間が過ぎたパスコードは自動失効・自動削除され、第三者は入室できない。

・入退室イベント・鍵電池残量・カメラ稼働状態を管理者がダッシュボードで一元確認できる。

・入口カメラの映像が自前NVR(Frigate)に常時録画され、施術エリアは一切映らない。

■ 想定する効果

・人件費ゼロ運営。鍵受け渡し作業・締め出し対応の削減。

・スマートロック月額(約2,200円/扉)の回避による固定費削減。

・予約・入退室・録画の証跡が残り、トラブル時の対応根拠になる。

■ 本書の位置づけ

本スプレッドシートは『要件定義→基本設計→詳細設計→テスト設計→実装指示』を1ファイルに集約した設計書一式である。最終シート群(40〜42)の手順に従い、リポジトリへ書き出してClaude Codeに渡すことで実装まで完了できる粒度を目標とする。
