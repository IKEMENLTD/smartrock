# 22_DB物理設計

詳細設計｜DB物理設計

Prisma/PostgreSQL前提。型・制約・キー・索引

■ TBL-001 stores

- カラム | 型 | 制約 | 説明
- id | BIGINT | PK, AUTO | 店舗ID
- name | TEXT | NOT NULL | 店舗名
- timezone | TEXT | NOT NULL, default 'Asia/Tokyo' | TZ
- google_calendar_id | TEXT | NULL | ミラー先カレンダーID
- switchbot_lock_id | TEXT | NULL | 鍵deviceId
- switchbot_keypad_id | TEXT | NOT NULL | キーパッドdeviceId(createKey対象)
- switchbot_hub_id | TEXT | NULL | HubのdeviceId
- booth_count | INT | NOT NULL, default 1 | ブース数
- created_at | TIMESTAMPTZ | NOT NULL, default now() | 作成
■ TBL-002 booths / TBL-003 business_hours

- カラム | 型 | 制約 | 説明
- booths.id | BIGINT | PK | ブースID
- booths.store_id | BIGINT | FK→stores | 所属店舗
- booths.name | TEXT | NOT NULL | ブース名
- business_hours.id | BIGINT | PK | 設定ID
- business_hours.store_id | BIGINT | FK→stores | 店舗
- business_hours.weekday | INT | NOT NULL(0=日..6=土) | 曜日
- business_hours.open_time | TIME | NOT NULL | 開店
- business_hours.close_time | TIME | NOT NULL | 閉店
- business_hours.slot_minutes | INT | NOT NULL, default 60 | 枠長(分)
- business_hours.buffer_minutes | INT | NOT NULL, default 15 | 枠間バッファ
■ TBL-004 customers / TBL-005 menus

- カラム | 型 | 制約 | 説明
- customers.id | BIGINT | PK | 顧客ID
- customers.line_user_id | TEXT | UNIQUE, NOT NULL | LINE userId
- customers.display_name | TEXT | NULL | 表示名
- customers.email | TEXT | NULL | 連絡先
- customers.agreed_terms_at | TIMESTAMPTZ | NULL | 規約同意日時
- menus.id | BIGINT | PK | メニューID
- menus.store_id | BIGINT | FK→stores | 店舗(NULLで全店共通)
- menus.name | TEXT | NOT NULL | 名称
- menus.duration_minutes | INT | NOT NULL | 所要分
- menus.price_yen | INT | NOT NULL | 料金(円)
■ TBL-006 reservations（中核）

- カラム | 型 | 制約 | 説明
- id | BIGINT | PK | 予約ID
- customer_id | BIGINT | FK→customers, NOT NULL | 顧客
- store_id | BIGINT | FK→stores, NOT NULL | 店舗
- booth_id | BIGINT | FK→booths, NOT NULL | ブース
- menu_id | BIGINT | FK→menus, NOT NULL | メニュー
- start_at | TIMESTAMPTZ | NOT NULL | 開始
- end_at | TIMESTAMPTZ | NOT NULL | 終了
- status | TEXT | NOT NULL(pending/confirmed/cancelled/done/no_show) | 状態
- google_event_id | TEXT | NULL | カレンダーミラーID
- amount_yen | INT | NOT NULL default 0 | 金額
- payment_status | TEXT | NOT NULL(none/unpaid/paid/refunded) | 決済状態
- created_at | TIMESTAMPTZ | default now() | 作成
⚠ 二重予約防止：(booth_id, start_at) に UNIQUE制約 + 予約作成時にトランザクション内で時間帯重複SELECT...FOR UPDATEを行う。

■ TBL-007 passcodes（非同期idに注意）

- カラム | 型 | 制約 | 説明
- id | BIGINT | PK | 内部ID
- reservation_id | BIGINT | FK→reservations, UNIQUE | 対象予約
- switchbot_device_id | TEXT | NOT NULL | キーパッドdeviceId
- switchbot_key_id | INT | NULL | createKey結果webhookで後埋め(削除に必須)
- passcode_name | TEXT | UNIQUE per device | createKeyのname(例 r{reservationId})
- code_hash | TEXT | NOT NULL | 暗証番号のハッシュ(平文非保持)
- type | TEXT | NOT NULL default 'timeLimit' | 種別
- valid_from | TIMESTAMPTZ | NOT NULL | 有効開始(start-10m)
- valid_to | TIMESTAMPTZ | NOT NULL | 有効終了(end+15m)
- status | TEXT | NOT NULL(pending/active/deleted/failed) | 状態
■ TBL-008 access_logs / TBL-009 scheduled_tasks

- カラム | 型 | 制約 | 説明
- access_logs.id | BIGINT | PK | ID
- access_logs.store_id | BIGINT | FK→stores | 店舗
- access_logs.reservation_id | BIGINT | FK NULL | 推定紐付け
- access_logs.device_id | TEXT | NOT NULL | device
- access_logs.event_type | TEXT | NOT NULL(locked/unlocked/door_open等) | 種別
- access_logs.occurred_at | TIMESTAMPTZ | NOT NULL, INDEX | 発生時刻
- access_logs.raw_json | JSONB | NOT NULL | 元payload
- scheduled_tasks.id | BIGINT | PK | ID
- scheduled_tasks.type | TEXT | NOT NULL(issue_passcode/revoke_passcode/send_reminder/send_thanks/expire_unpaid) | 種別
- scheduled_tasks.reservation_id | BIGINT | FK NULL | 対象
- scheduled_tasks.run_at | TIMESTAMPTZ | NOT NULL, INDEX | 起動時刻
- scheduled_tasks.status | TEXT | NOT NULL(scheduled/running/done/failed/cancelled) | 状態
- scheduled_tasks.attempts | INT | NOT NULL default 0 | 試行回数
- scheduled_tasks.last_error | TEXT | NULL | 直近エラー
- scheduled_tasks.payload_json | JSONB | NULL | 付帯データ
